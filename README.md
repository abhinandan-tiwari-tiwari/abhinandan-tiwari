# Abhinandan Tiwari — Portfolio

A responsive, single-file portfolio website with a black / grey / gold theme and scroll-reveal animations.

## Publish with Cloudflare Pages
1. Create a GitHub repository named `abhinandan-portfolio`.
2. Upload `index.html` to the repository root.
3. In Cloudflare Dashboard, open **Workers & Pages → Create → Pages → Connect to Git**.
4. Select this repository.
5. For a plain HTML site, leave the build command empty and set the build output directory to `/` (or `.` if the dashboard requires a relative path).
6. Deploy. Cloudflare will provide a `*.pages.dev` address.

## Personalize before sharing
- Replace `YOUR_EMAIL@example.com` in the contact button with your real email.
- Replace the four project placeholder cards with screenshots/images and descriptions of your actual work.
- Add your real Instagram / WhatsApp links if you want them.
- Check the site on mobile after publishing.

The project cards are placeholders, not claims of completed client work. No client counts, testimonials, or credentials have been invented.
